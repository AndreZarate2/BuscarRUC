Origen y alcance de los datos

Se utiliza el padrón reducido de SUNAT (RUC que empiezan por 20), directorios de entidades públicas de PCM y referencias documentales de proyectos especiales. La fecha de actualización se indica en la parte superior.

  • SUNAT · Padrón reducido RUC
  • PCM · Directorio de entidades públicas
  • Un proyecto puede tener un RUC propio, compartir el de una entidad o constar solo en referencias documentales.

Consideraciones para la consulta

La ubicación SUNAT corresponde al domicilio fiscal, que puede ser distinta del lugar donde opera la entidad. La ubicación de proyectos sin contraste SUNAT es referencial.

Una página estática no actualiza por sí sola el padrón: la actualización se realiza mediante GitHub Actions. Este buscador no consulta el estado del RUC en tiempo real.

Para evitar que el navegador se bloquee, una búsqueda conserva como máximo 250 000 registros exportables. Si el filtro supera ese límite se informa expresamente.
